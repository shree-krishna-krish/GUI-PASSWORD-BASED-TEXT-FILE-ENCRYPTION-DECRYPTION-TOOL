# GUI-PASSWORD-BASED-TEXT-FILE-ENCRYPTION-DECRYPTION-TOOL
Python GUI app for encrypting/decrypting text and files. Built with Tkinter and the cryptography library, it derives keys from passwords using PBKDF2-HMAC-SHA256 and a 16-byte salt. Fernet handles the encryption, combining data into URL-safe Base64 for easy copying. Ideal for learning key derivation and secure interface design.
